Notices for what the playground downloads
=========================================

Pressing a button on https://agda-algebras.universalalgebra.org/playground/
fetches a build of Agda compiled to WebAssembly and one or more filesystem
images: archives of Agda source files and the compiled interface files the
checker needs.  Those files are the work of the projects below and reach you
under their terms, which are reproduced here in full.

Versions: Agda 2.8.0; the Agda standard library 2.3; agda-wasm-dist release
v2.8.0-ghc9.10.3-r0.  The manifest published beside this file
(manifest.json) lists each image's module closure, and the commit of
ualib/agda-algebras and the standard library's store path it was built from;
every image also carries Agda's builtin modules, section 2.
