{#- File: overrides/404.html The 404 page as an Agda goal that cannot be filled (#621). GitHub Pages serves 404.html from the site root for every URL that resolves to nothing, so this is the one page every mistyped link reaches. Material's default is `

404 - Not found

` over the full docs frame. This file shadows it (Material resolves templates from `custom_dir` first) and sets the page as a goal. The design is williamdemeo.org's; the goal here is set in Agda's own token classes, `
`
  with `Function`, `Symbol` and `Hole` spans, so agda.css colors it exactly
  as it colors every code block on the site.

  Part of the shareable theme: it names nothing of this site's but its
  index and its search, so a sibling site copies it unchanged.

  Four blocks are overridden:

    htmltitle  MkDocs renders error templates with no `page` object, so the
               default title collapses to the bare site name.
    extrahead  The styles, scoped to this page, in tokens like every other
               stylesheet; last in , they win cascade ties.
    site_nav   Emptied.  The navigation sidebar is the docs frame, and a
               wrong URL is not a docs page; search stays in the header.
    content    The goal itself.

  URLs: MkDocs renders error templates with base_url taken from site_url's
  *path* ('/'), not a relative prefix, so the links below resolve however
  deep the missing URL is.  That is also why this page cannot be previewed
  from file://; use `make serve` and request any bogus path.

  The only motion is the comment line typing itself out once: pure CSS, one
  character per steps() frame over a clip-path, so the whole sentence is in
  the DOM from the start (a screen reader never waits), the box never
  changes size, and prefers-reduced-motion turns it off.

  The one script puts the missing URL's own path into the goal, since only
  the visitor's browser knows it.  It writes through textContent only (the
  path is attacker-chosen text and must never be parsed as markup), and the
  static `ThisPage` stands when scripts are off.

  Keep in step with the upstream template on a Material upgrade: the block
  names and the md-* classes are Material's (9.7.6).
-#}
